## 產品授權

以統一編號綁定，不可跨公司轉讓；POS 有效付費客戶在授權範圍內免費使用兩套標準版。線上訂位試用不開放訂金付款，訂位系統目前不與 POS 串接。

## 2026-11 定價草案更新

- 打卡差勤：基本免費版 $0、標準版 NT$299/月、專業版 NT$499/月、企業版 NT$999/月起。
- **LINE 直接打卡包含在標準版 $299/月內**，不另收費。
- 線上訂位保留旗艦版、取消連鎖版，標準版 NT$799/月、旗艦版 NT$1,299/月；試用 14 天不開放訂金付款。
- 促銷文案採「每天平均只要約 NT$10／17／27」，以月費除以 30 天計算，實際仍按月收費。
- 所有價格與人數均為待核定建議，並非正式報價。
