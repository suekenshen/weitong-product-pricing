# 唯統科技｜產品功能與報價討論版

## 發布 GitHub Pages

Repository → Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
發布後預計網址：`https://suekenshen.github.io/weitong-product-pricing/`（須實際啟用後才可使用）。

## 產品授權

以統一編號綁定，不可跨公司轉讓；POS 有效付費客戶在授權範圍內免費使用兩套標準版。線上訂位試用不開放訂金付款，訂位系統目前不與 POS 串接。
